# Not-a-Doom

Классический псевдо-3D / 2.5D ретро-шутер на Python и Pygame, вдохновленный культовыми играми 90-х (*DOOM*, *Wolfenstein 3D*, *Heretic*).

## Архитектура проекта

Проект организован по модульным пакетам:
- **`src/core/`**: настройки (`settings.py`), карта лабиринта (`map.py`), математика DDA рейкастинга (`raycasting.py`).
- **`src/entities/`**: контроллер игрока (`player.py`), демонические враги с AI поиском пути и атаками (`enemy.py`).
- **`src/combat/`**: оружие и анимации дробовика (`weapon.py`), огненные шары (`projectile.py`), 3D частицы крови, искр и взрывов (`particles.py`).
- **`src/graphics/`**: 3D рендерер и экраны (`renderer.py`), процедурные текстуры стен (`textures.py`), 2.5D спрайты, бочки, аптечки и портал (`sprite_object.py`).
- **`src/audio/`**: 16-битный ретро-движок процедурного синтеза звуков (`sound.py`).
- **`main.py`** / **`src/main.py`**: входные точки и главный игровой цикл.

## Возможности
- [x] Инициализация проекта и базового окружения
- [x] Окно и игровой цикл (Game Loop) с дельта-таймом
- [x] Карта уровней и секторная/лучевая DDA геометрия
- [x] Рендерер с O(1) предпросчитанными картами освещения и панорамным скроллингом неба
- [x] Управление игроком (WASD + стрелки, захват мыши, стрейфы) и физика скольжения вдоль стен
- [x] Система здоровья, урон от атак, красная вспышка экрана и экран смерти
- [x] 2.5D летающие какодемоны с анимациями, AI зрением, реакцией на шум выстрела и ближним/дальним боем
- [x] Двуствольный дробовик с фасетчатым пиксель-артом, анимацией отдачи и перезарядки
- [x] 3D частицы брызг крови, рикошетных искр и огненных взрывов
- [x] Интерактивные подбираемые аптечки (+25 HP) с исцеляющей вспышкой
- [x] Взрывающиеся радиоактивные бочки со сплэш-уроном и цепной детонацией
- [x] Портал выхода на уровне, экран победы с подсчетом убийств и времени
- [x] Процедурный 16-битный звуковой движок без внешних аудио-зависимостей

## Запуск
```bash
# Активация виртуального окружения
.\venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск игры
python main.py
```
*(Или двойной клик по `run.bat`)*

# Not-a-Doom

Классический псевдо-3D / 2.5D ретро-шутер на Python и Pygame, вдохновленный культовыми играми 90-х (DOOM, Wolfenstein 3D, Heretic).

## Возможности (в разработке)
- [x] Инициализация проекта и базового окружения
- [ ] Окно и игровой цикл (Game Loop) с дельта-таймом
- [ ] Карта уровней и секторная/лучевая геометрия
- [ ] Рендерер с текстурированием стен, пола и потолка
- [ ] Управление игроком (WASD + стрейфы + мышь)
- [ ] Спрайты врагов и объектов с сортировкой по глубине
- [ ] Оружие, анимации и звуковые эффекты
- [ ] HUD (здоровье, патроны, лицо героя)

## Запуск
```bash
# Активация виртуального окружения
.\venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск
python src/main.py
```
